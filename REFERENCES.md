# References

This bibliography lists only sources named in `@[source ...]` attributes on declarations in
`SICs/`, `SICs.lean`, and `MainResults.lean`. The count for each source is the number of distinct
declarations tagged to it, counting a declaration once per source even if its tag cites several
statements from that source. Sources cited only in comments or docstrings are omitted.
Entries are ordered by decreasing declaration count. All arXiv links use the versions pinned
by the project.

Numeric citations such as `[72]` refer to the corresponding bibliography entry in
[AFK25, Appleby, Flammia, Kopp (2025)]. Lettered keys such as `[RW26]` identify sources outside
that bibliography, following the citation scheme used in the Lean source comments.
